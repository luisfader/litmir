*Полезные фразы для каждого места, где прятался Алекс. Пригодятся в любом городе — даже если вас никто не ищет.*

### At a café

| Phrase | Перевод |
| Could I have a cappuccino, please? | Можно мне капучино? |
| Is this seat free? | Это место свободно? |
| Could we have the bill, please? | Принесите, пожалуйста, счёт. |
| Can I pay by card? | Можно расплатиться картой? |

### At a museum

| Phrase | Перевод |
| Two adult tickets, please. | Два взрослых билета, пожалуйста. |
| Is there a discount for students? | Есть скидка для студентов? |
| Where is the cloakroom? | Где гардероб? |
| Who painted this picture? | Кто написал эту картину? |
| Am I allowed to take photos? | Здесь можно фотографировать? |

### At a market

| Phrase | Перевод |
| How much is a kilo of tomatoes? | Сколько стоит килограмм помидоров? |
| Can I try some? | Можно попробовать? |
| Is it fresh? | Это свежее? |
| I'll take half a kilo, please. | Я возьму полкило, пожалуйста. |
| Could you clean the fish for me? | Почистите мне рыбу, пожалуйста. |

### In the metro

| Phrase | Перевод |
| Which line goes to the centre? | Какая линия идёт в центр? |
| Where do I change for the Circle Line? | Где пересадка на Кольцевую? |
| How many stops is it? | Сколько остановок? |
| Is this the right platform? | Это правильная платформа? |
| Excuse me, I'm getting off. | Простите, я выхожу. |

### In a park

| Phrase | Перевод |
| Where can I hire a boat / a bike? | Где можно взять напрокат лодку / велосипед? |
| How much is it per hour? | Сколько стоит в час? |
| Are dogs allowed here? | Сюда можно с собаками? |
| What time does the park close? | Во сколько закрывается парк? |

### At the zoo and the planetarium

| Phrase | Перевод |
| What time is feeding time? | Когда кормление животных? |
| Please don't feed the animals. | Пожалуйста, не кормите животных. |
| When does the next show start? | Когда начинается следующий сеанс? |
| Is the show suitable for children? | Сеанс подходит для детей? |

### In a library

| Phrase | Перевод |
| I'd like to get a library card. | Я хотел бы записаться в библиотеку. |
| How long can I keep this book? | На сколько можно взять эту книгу? |
| Is there Wi-Fi here? | Здесь есть вайфай? |
| Could you help me find…? | Не поможете найти…? |

### In a banya / a spa

| Phrase | Перевод |
| Do I need to book in advance? | Нужно бронировать заранее? |
| Are towels included? | Полотенца включены в стоимость? |
| It's too hot for me. | Мне слишком жарко. |
| Where are the changing rooms? | Где раздевалки? |

### In a shop

| Phrase | Перевод |
| I'm just looking, thanks. | Я просто смотрю, спасибо. |
| Could I try this on? | Можно это примерить? |
| Have you got this in a smaller / bigger size? | Есть размер поменьше / побольше? |
| It's too tight / too loose. | Слишком тесно / слишком свободно. |
| Can I return it if it doesn't fit? | Можно вернуть, если не подойдёт? |

### At the hairdresser's

| Phrase | Перевод |
| I'd like a haircut, please. | Я хочу подстричься. |
| Just a trim, please. | Только подровнять, пожалуйста. |
| Not too short, please. | Не слишком коротко, пожалуйста. |
| Could you dye it dark brown? | Можно покрасить в тёмно-каштановый? |

### On television (if you are ever accused of being an alien)

| Phrase | Перевод |
| That's not true, and I can prove it. | Это неправда, и я могу это доказать. |
| Could you tell us where you got this information? | Не могли бы вы сказать, откуда у вас эта информация? |
| I'd like to see the evidence. | Я хотел бы увидеть доказательства. |
| With respect, that's nonsense. | При всём уважении, это чепуха. |
| Shall we laugh about it together? | Может, посмеёмся над этим вместе? |

### Final Exercise

Переведите на английский, используя фразы из разговорника.

1. Можно это примерить? Есть размер побольше?

2. Где пересадка на Кольцевую линию?

3. Сколько стоит килограмм помидоров? Можно попробовать?

4. Только подровнять, пожалуйста. Не слишком коротко.

5. Не могли бы вы сказать, откуда у вас эта информация?

6. Когда начинается следующий сеанс?
