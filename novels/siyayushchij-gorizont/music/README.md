# Саундтрек романа «Сияющий горизонт»

Три оригинальные записи опубликованы в этой папке. Чтобы не терять качество и безопасно передать большие MP3-файлы, каждый исходный файл был **разделён на двоичные части без перекодирования**. Браузер загружает части, собирает исходный MP3 и включает его только после нажатия читателем кнопки воспроизведения.

| Трек | Название | Длительность | Части |
|---|---|---|---|
| 01 | Душа в бункере | 3:09 | `01/000.part` … `01/030.part` (31) |
| 02 | Дождь любви | 2:38 | `02/000.part` … `02/015.part` (16) |
| 03 | Завтра будет дождь | 4:12 | `03/000.part` … `03/023.part` (24) |

**Важное:** не переименовывайте и не удаляйте файлы `.part`. Роман использует пути и количество частей, указанные в `novels/catalog.json`. Код плеера находится в `index.html`. Музыка никогда не запускается автоматически, а при переключении между главами воспроизведение продолжается.

**Оригинальные размеры файлов:** 7 568 239 / 3 810 372 / 5 871 745 байт. Суммарный размер двоичных частей совпадает с исходными MP3-файлами.
