# Саундтрек романа «Волны любви. Крепость в полумраке»

Оригинальные записи опубликованы в этой папке. Чтобы не терять качество и безопасно передать большие MP3-файлы, каждый исходный файл **разделён на двоичные части без перекодирования**. Браузер загружает части, собирает исходный MP3 и включает его только после нажатия читателем кнопки воспроизведения.
